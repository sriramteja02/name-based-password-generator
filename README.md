Name-Based Password Generator

A Python-based password generator that creates secure and customized passwords using user-provided words. The project uses random casing, symbols, digits, and leet transformations to generate stronger passwords. It also includes password strength validation and configurable password rules.

Features
Custom password generation
Random symbols and digits
Password strength checking
Secure randomization using Python
Technologies Used
Python
Regex
Secrets Module
